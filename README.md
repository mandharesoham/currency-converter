# 💱 Currency Converter

A simple currency converter web application built using HTML, CSS and JavaScript.

## 🚀 Live Demo

[Try Currency Converter](https://currency-converter-gules-seven.vercel.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Exchange Rate API

## ✨ Features

- Convert between different currencies
- Live exchange rates
- Currency flags
- Simple and responsive interface
- User-friendly design
